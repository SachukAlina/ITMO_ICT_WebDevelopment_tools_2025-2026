# Практика 1.1

Базовое FastAPI-приложение с временной базой данных. Главная модель
`LibraryEntry` содержит одиночные вложенные объекты владельца и книги, а книга
содержит список авторов. Реализованы типизированные CRUD-эндпоинты и отдельное
API вложенной модели автора.

Запуск из этой папки:

```bash
uvicorn main:app --reload
```
