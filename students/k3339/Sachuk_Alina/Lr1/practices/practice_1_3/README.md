# Практика 1.3

В итоговый проект добавлены:

- миграции Alembic в `migrations/`;
- получение URL базы из переменной `DATABASE_URL` через `app/config.py`;
- безопасный шаблон `.env.example`;
- исключение настоящего `.env`, виртуального окружения и кэшей в `.gitignore`;
- разбиение приложения на модели, схемы, маршруты, безопасность и presenters.

Команда применения миграций:

```bash
alembic upgrade head
```
